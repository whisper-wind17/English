## 范围与证据

当前全册来源表的906条出现记录均已完成目标义项判断、稳定身份映射和学习内容审核；对应889个不同学习目标。原始来源文件不改写：前150条保留实物照片证据；后756条保留 `baseline-reconciled`，另由 `nce1/source_senses/batch_002.csv` 记录本次逐项语境、词性、目标释义、参考出处和模型审核。**不把网络旧版参考冒充2022智慧版逐页实物核验**。

## 身份与去重

全册889个目标中，618个复用此前的既有身份，271个为新词或需要独立学习的义项（包括首批41个）。本次续批新增230个身份 `KV003057–KV003286`，全部在旧ID后追加。此前3,056个身份记录不变；首批数据和历史审核凭据保留。

空格、连字符、缩写句点和英美拼写等同一目标复用：ice cream → ice-cream、Mrs. → Mrs、stomach ache → stomachache、tyre → tire。shoe按现有重复治理选择KV000256 shoes为存续目标，KV002569继续暂停。full满的/饱的、bank河岸/银行、miss错过/想念等不同目标保留独立身份与题面提示。后续low复现复用本批先前ID，不重复分配。

已有同形笔记58条增加提示或收窄展示至旧例句实际教授的目标；不改身份字段，不删除旧卡。新内容有明确模型审核凭据，模型审核不冒充人工审核。词汇表内固定词组按词汇识别目标处理，不机械生成新的Expressions卡。
